# Manuel d'arr

`arr` aide un groupe à travailler ses reprises : capturer un morceau, le découper en pistes,
jouer par-dessus, s'enregistrer, et faire rejouer le morceau entier par un groupe virtuel
dans un autre style. Tout tourne sur la machine.

Le [README](../../README.md) du dépôt est un aperçu rapide. Ce manuel est la documentation
complète.

| Page | Contenu |

| [Installation](installation.md) | prérequis, installation, modèles, vérification, mise à jour |
| [Notions](notions.md) | projet, pistes, versions, prises, sections : le vocabulaire de l'outil |

## Par où commencer

1. [Installation](installation.md), jusqu'à ce que `arr doctor` dise que tout est présent.
2. [Configuration audio](audio.md), jusqu'à ce que `arr levels` montre le son sur les bons
   canaux. Cette étape dépend de votre matériel : ne la sautez pas.
3. [Parcours](parcours.md), en commençant par « Travailler un morceau ».
